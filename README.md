# Better With Hands

[![GitHub release](https://img.shields.io/github/v/release/MinecraftLabs/better-with-hands?color=orange)](https://github.com/MinecraftLabs/better-with-hands/releases)
[![Modrinth downloads](https://img.shields.io/modrinth/dt/better-with-hands?color=orange&logo=modrinth)](https://modrinth.com/mod/better-with-hands)

Ever noticed that Steve technically has two hands?

Steve finally learned how to use both arms.

Better With Hands adds an offhand to Better Than Adventure. Hold a torch while you mine, keep blocks ready while you explore, or fight with a sword in each hand.

### Features

- Offhand slot in the inventory, right under the crafting result
- Offhand item shown in first and third person, with its own swing animation
- Offhand slot next to the hotbar, movable in the HUD editor
- Picked up items go into the offhand first when they stack with it
- Two swords: left click hits with the left hand, right click with the right hand
- Follows the game's left-handed setting
- Works in multiplayer, the server needs the mod too

### Controls

| Key | Action |
|-----|--------|
| **F** | Swap items between hands |
| **X** | Toggle which hand is used first |

Both keys can be rebound in Options.

### Settings

Found in **Options > Better With Hands**.

- **Use Offhand When Main Empty** (on): with an empty main hand, the offhand does the work
- **Swap Hand Priority** (off): the offhand is used first, same as pressing X
- **Dynamic Hand Priority** (off, experimental): picks the hand for you. The faster tool for mining, the sword for fighting, the block for right click
- **Indicator Type**: Border, Vanilla, Dot, Arrow or None
- **Show Indicator Only With Offhand** (on)
